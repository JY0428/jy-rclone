JY rclone 개인정보처리방침

시행일: 2026년 11월 10일

접근하는 정보

JY rclone은 Google Drive 권한(https://www.googleapis.com/auth/drive)으로 사용자의 Google Drive 파일과 폴더 정보에 접근합니다.

사용 목적

접근한 정보는 소유자 본인의 파일을 rclone으로 올리고, 내려받고, 동기화하는 데에만 사용합니다.

공유와 보관

Google 사용자 데이터는 제3자에게 공유, 판매, 전송하지 않습니다. 인증 토큰은 소유자 본인의 기기에만 저장되며, 광고나 분석 도구는 사용하지 않습니다.

Google API 정책 준수

JY rclone이 Google API로 받은 정보의 사용과 전송은 제한적 사용(Limited Use) 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

접근 권한 철회

Google 계정의 타사 연결 페이지에서 언제든 접근 권한을 철회할 수 있습니다.
